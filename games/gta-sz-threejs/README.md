# GTA_SZ Three.js mobile port

This mobile Three.js implementation reads the OSM-derived city database produced by `linranff/GTA_SZ` at runtime and renders it with a mobile-oriented batching/streaming strategy.

- Roads/building footprints: © OpenStreetMap contributors, ODbL 1.0.
- City data preparation/source project: `linranff/GTA_SZ`.
- Player concept car: Khronos glTF Sample Assets `CarConcept`, © 2024 Darmstadt Graphics Group GmbH / Eric Chadwick, CC BY 4.0.
- Restricted character models from the source project are not redistributed here.
- Source code in this folder is an independent Three.js implementation rather than a copy of GTA_SZ's Babylon.js runtime.
