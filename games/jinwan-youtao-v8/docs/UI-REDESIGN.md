# 《今晚有套吗？》UI v9 — 信息架构与组件验收规范

## 目标
仅重构管理界面的导航、文案与组件样式；保留 Three.js 场景、经营命令、存档结构、事件推进与数值模型。当前状态：**待真机视觉验收**。

## 统一信息架构（一级 > 二级 > 详情）
- **总览**：今日 / 晨会 / 目标 / 复盘 / 日志 / 设置
  - 详情：需求预测、日常奖励、成长里程碑、开业带教、客诉与建议
- **客房**：房态 / 扩建
  - 详情：房间详情、空间总览
- **宾客**：接待 / 待办 / 预订 / 客史
  - 详情：客史详情
- **运营**：团队 / 安排 / 财务 / 评分
  - 详情：财务明细
- **发展**：设施 / 活动

唯一归属由 `src/ui/navigation.ts` 的 `MENU_OWNER` 控制。跨栏推荐只能作为页面中的“相关页面”链接，不能复制进另一个栏目的二级菜单。深层详情用 `PARENTS` 指向所属的二级栏目；`activeModule` 必须保持该栏目高亮。

## 层级示例

```
酒店3D主场景

      ├─ 上栏：返回 / 当前栏目 · 当前页面 / 关闭
      ├─ 二级栏目：可横向滑动，当前项高亮
      ├─ 主体：一项页面任务、数据与可滚动详情
      ├─ 相关页面：仅跳转，不做经营决策
      ├─ 固定经营操作区：决策、确认、执行
      └─ 一级导航：与主场景同名同序
```

## 组件和文案规则
| 要素 | UI v9 标准 | 约束 |
|---|---|---|
| 一级导航 | 5 个，图标 + 双字标签 | 场景和弹窗同序；不得重复子菜单 |
| 二级导航 | 标签高度 ≥36px，字号 12px | 只出现归属本栏的功能 |
| 页面标题 | 19–21px，粗体 | 用“处理对象 + 当前任务”，避免与导航混用 |
| 正文 | 13px；辅助文字 11–12px | 保留代价、时长、前置条件 |
| 数字指标 | 18px 左右、等宽数字 | 现金 `¥`、房间 `间`、时间 `分钟` 明确 |
| 经营按钮 | 高度 ≥46px；主要操作用绿色 | 多个互斥选项同等权重，不武断突出首项 |
| 跨页按钮 | 移到正文末尾的“相关页面” | 与执行经营命令物理分区 |
| 返回 | 优先返回实际历史位置 | 保留房间选择、分页、滚动位置 |
| 底部一级导航 | 始终可见（超矮屏保留文字） | 不占据正文滚动区域 |

**文案词表**：统一使用“总览、客房、宾客、运营、发展 / 房态、扩建、接待、待办、预订、客史、团队、安排、财务、评分、设施、活动”。不再让“酒店 / 客房”“客人 / 前台 / 宾客”“运营 / 团队”在同一导航层级互相替代。

## 核心交互验收
1. 从 3D 房间点入客房管理、再点房间详情，客房二级“房态”继续高亮，返回恢复此前房间和滚动。
2. 从客房跳“查看服务诉求”进入宾客 / 待办；页面上“相关页面”和执行决策分区，底部主导航指向宾客。
3. 同一功能不能同时在两个一级栏目出现二级入口（财务只属于运营；扩建只属于客房）。
4. 任一页面的多个替代决策，不因按钮在 DOM 中排第一就自动获得“主操作”强调。
5. 320、375、390、430、560px 视口宽度，以及 iPhone 安全区：无遮挡、无横向溢出、可触控；滚动不触发酒店楼层滑动。
6. 小高度、字体放大、低动态效果模式：菜单仍可访问；弹窗能关闭，经营行为可完成。
7. 旧存档可加载，核心经营指令及 `npm test` + `npm run build` 均通过。
