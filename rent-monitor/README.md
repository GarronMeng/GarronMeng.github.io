# 香港租房雷达

公开租盘的自动收集、地区分类、户型合并和条件比较工具。数据来自公开房源网页，经 GitHub Actions 定时抓取。

## 通用筛选标准

- 常规独立住宅；排除合租、劏房、学生及员工宿舍、村屋、短租与非住宅用途
- 面积参考：300 呎以上；可在 250–299 呎范围内查看条件权衡盘
- 租金参考：15,000 港元内优先；18,000 港元内权衡；更高价格作为机会观察
- 优先考虑有电梯、分体冷气、干湿分离，以及距港铁步行约 5 分钟的房源
- 区域和户型都可分组展示；同规格或同户型广告合并展示，但保留原始广告链接

## 通勤信息

显示公开的港铁路线、车站和步行时间，并提供早班交通便利度参考。首班列车、站点实际到达时间及步行路程未逐一核实，不应将推荐标签当作到站保证。

## 数据与去重

- `scripts/scrape.py`：地区房源发现和详情验证
- `scripts/scrape_v22.py`：扩充地区、调用分组处理并生成公开数据
- `scripts/dedupe.py`：依房屋基本规格合并近似广告；相似广告不等于同一实际单位
- `data/listings.json`：公开市场房源信息和非个人化筛选数据
- `app.js`：A/B/C 评级、地区导航、租金与面积比较
- `.github/workflows/rent-monitor.yml`：定时刷新和自动化测试

## 隐私边界

公开网站不需要存储个人姓名、家庭地址、居住单位、个人精确工作时间或既有住房的实际租金和面积。比较基准采用公开的、通用的筛选门槛。任何新功能都应避免将个人资料放进 GitHub Pages 的 HTML、JavaScript、JSON 或配置文件。

请注意：清理最新文件不会自动删除既有 Git 提交历史、第三方缓存或已经被他人复制的版本。
