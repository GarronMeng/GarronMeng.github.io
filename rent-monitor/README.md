# 香港租房雷达

静态网页 + GitHub Actions 自动刷新香港租盘。

## 当前筛选基准
- 当前住房：基安大厦 10C，HK$11,000 / 224呎
- 核心目标：≥300呎、≤HK$14,000、常规独立住宅、有电梯、分体冷气、步行港铁≤5分钟、无需换乘直达金钟
- 候选池：≥280呎、≤HK$15,000、步行港铁≤10分钟；未确认电梯/分体冷气的房源可作为待核候选，但不会进入“核心达标”
- 干湿分离为重要加分项

## 房源类型硬排除
在评分前直接剔除：
- 村屋、丁屋、围村住宅
- 学生宿舍、学生公寓、共居/Co-living、床位盘
- 员工/劳工/外劳宿舍
- 分间单位、劏房、合租、单房出租
- 服务式住宅、酒店式/月租公寓、短租
- 工商/工业/工厂大厦、办公室、商铺、货仓
- 已下架、详情页跳转到其他房源的链接

“欢迎学生/可租学生”本身不会排除正常私人屋苑；只有明确属于学生宿舍、共居或学生专用年付模式才会剔除。

## 交通验证
不再使用“所在区域 = 最近港铁站”的假设。详情页必须明确出现具体港铁站名称及步行分钟数，或明确写明港铁上盖/楼下地铁，才进入候选池。

只认可可单线直达金钟的具体站点：荃湾线、港岛线、东铁线。比如“荃湾西站”属于屯马线，即使房源地址写荃湾区，也不会被当成“荃湾线直达金钟”。核心达标要求步行≤5分钟，候选池最多10分钟。

## 评分逻辑
先过资格门槛，再评分。大面积和低租金不能覆盖住宅类型、交通或基本居住条件缺陷。

主要评分维度：
- 相比基安大厦增加的实用面积
- 租金与HK$14,000目标的差距
- 分体式/挂墙式冷气
- 干湿分离
- 电梯
- 港铁步行时间
- 一房优先，其次两房/开放式
- 东铁线去深圳便利性
- 与现住房相比“每多付一元换来的居住升级”
- 新盘/降价盘

已明确为窗口式冷气或无电梯步梯楼的房源直接剔除；冷气/电梯未写清楚的可以留在候选池，但不能进入核心达标。

## 监控范围
- 荃湾线方向：荃湾、葵芳、美孚、荔枝角、长沙湾、深水埗、太子、旺角、油麻地、佐敦
- 港岛线东段：北角、鰂鱼涌、西湾河、筲箕湾、柴湾
- 东铁线：红磡、大围、沙田、火炭、大埔墟/大埔、太和、粉岭、上水

范围页只是“发现入口”，最终路线仍以每套详情页解析出来的实际港铁站为准。

## 自动刷新
