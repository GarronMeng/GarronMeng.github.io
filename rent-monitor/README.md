# 香港租房雷达

静态网页 + GitHub Actions 自动刷新香港租盘。

## 当前筛选基准
- 当前住房：基安大厦 10C，HK$11,000 / 224呎
- 核心目标：≥300呎、≤HK$14,000、常规独立住宅、有电梯、分体冷气、步行港铁≤5分钟、无需换乘直达金钟
- 候选池：≥280呎、≤HK$15,000、步行港铁≤10分钟；未确认电梯/分体冷气的房源可作为待核候选，但不会进入“核心达标”
- 干湿分离为重要加分项

## 房源类型硬排除
在评分前直接剔除：
- 村屋、丁屋、围村住宅
- 学生宿舍、学生公寓、共居/Co-living、床位盘
- 分间单位、劏房、合租、单房出租
- 服务式住宅、酒店式/月租公寓、短租
- 工商/工业/工厂大厦、办公室、商铺、货仓
- 已下架、详情页跳转到其他房源的链接

“欢迎学生/可租学生”本身不会排除正常私人屋苑；只有明确属于学生宿舍、共居或学生专用年付模式才会剔除。

## 交通验证
区域名称不再等同于港铁距离。详情页必须能提取到目标港铁站的明确步行分钟数，或明确写明港铁上盖/楼下地铁，才会进入候选池。核心达标要求步行≤5分钟。

## 评分逻辑
先通过住宅类型、租金、面积、港铁距离等资格门槛，再评分。评分主要考虑：面积升级、租金、分体冷气、干湿分离、电梯、港铁步行距离、房型、深圳便利性和相对基安大厦的升级效率。大面积本身不会再覆盖住宅类型或交通缺陷。

## 监控范围
- 荃湾线：荃湾、美孚、荔枝角、长沙湾、深水埗、佐敦
- 港岛线：北角、鰂鱼涌、西湾河、筲箕湾
- 东铁线：红磡、沙田、粉岭、上水

## 自动刷新
